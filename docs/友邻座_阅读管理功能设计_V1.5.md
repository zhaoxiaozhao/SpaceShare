# 友邻座 V1.5 阅读管理功能设计文档

> 版本：2026年8月  
> 定位：围绕"学习空间服务"延伸，将低频座位工具升级为高频学习工具的**阅读管理模块**
> 对齐整改意见：功能必须与"学习"产生关系（原则五）

---

## 一、功能概述

阅读管理为用户提供**书籍登记、阅读计时、进度记录、摘抄笔记、阅读统计**的一站式阅读管理能力，与现有"学习记录"（study）模块并列，共同构成"学习留存层"。

### 核心闭环

```text
登记书籍 → 阅读计时 → 更新进度 → 摘抄/笔记 → 统计/报告
```

### 功能清单

| 模块 | 功能 |
|---|---|
| 书籍管理 | 书名、作者、封面（本地上传）、状态（想读/在读/已读） |
| 阅读计时 | 开始阅读 / 结束阅读 / 阅读时长自动累计（与学习计时同机制） |
| 进度记录 | 当前阅读进度（页数/百分比）、上次阅读位置（自由文本） |
| 摘抄 | 记录书中好句，支持收藏回看 |
| 我的笔记 | 每本书的阅读笔记 |
| 阅读历史 | 每次阅读会话记录 |
| 阅读统计 | 阅读时长、阅读日历、连续阅读天数 |
| 年度报告 | 年度阅读汇总报告 |

## 二、数据模型

新增 3 张表，复用餐馆（Venue）不关联场馆，阅读是纯个人工具。

### 1. ReadingBooks（书籍）

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | long | 主键 |
| UserId | long | 所属用户 |
| Title | string | 书名 |
| Author | string? | 作者 |
| CoverUrl | string? | 封面（微信云存储 URL） |
| Status | int | BookStatus：WantToRead=想读 / Reading=在读 / Finished=已读 |
| CurrentProgress | int | 当前阅读进度（页数，0 表示未记录） |
| TotalPages | int? | 总页数（用于计算百分比） |
| LastPosition | string? | 上次阅读位置（如"第3章 第5节"） |
| TotalMinutes | int | 累计阅读时长（分钟） |
| CreatedAt | DateTime | 创建时间 |
| UpdatedAt | DateTime | 更新时间 |

### 2. ReadingSessions（阅读会话/历史）

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | long | 主键 |
| UserId | long | 用户 |
| BookId | long | 关联书籍 |
| StartedAt | DateTime | 开始阅读（UTC） |
| EndedAt | DateTime? | 结束阅读（UTC） |
| DurationMinutes | int | 时长（分钟） |
| Status | int | ReadingSessionStatus：Active / Completed |

### 3. ReadingNotes（摘抄与笔记）

| 字段 | 类型 | 说明 |
|---|---|---|
| Id | long | 主键 |

## 三、API 设计

前缀：`/api/v1/reading`（需登录）

### 书籍
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/reading/books` | 添加书籍 |
| PUT | `/reading/books/{id}` | 更新书籍（信息/进度/位置/状态） |
| DELETE | `/reading/books/{id}` | 删除书籍 |
| GET | `/reading/books` | 我的书籍列表（含状态筛选） |
| GET | `/reading/books/{id}` | 书籍详情（含笔记/摘抄） |

### 阅读会话
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/reading/books/{id}/start` | 开始阅读 |
| POST | `/reading/books/{id}/end` | 结束阅读（自动累计时长+更新进度） |
| POST | `/reading/end-active` | 结束当前活跃会话 |
| GET | `/reading/sessions` | 阅读历史 |

### 摘抄笔记
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/reading/books/{id}/notes` | 添加摘抄/笔记 |
| DELETE | `/reading/notes/{id}` | 删除 |
| GET | `/reading/books/{id}/notes` | 书籍笔记列表 |

### 统计与报告
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/reading/stats` | 今日/本周/累计时长、连续阅读天数 |

| GET | `/reading/yearly-report?year=` | 年度阅读报告 |

## 四、核心逻辑

### 1. 阅读计时（复用 study 同机制）
- 同一用户同一时间只允许 1 个活跃阅读会话（与学习会话独立，可并行）
- 开始阅读：创建 Active 会话；结束：算时长（UTC→中国时区），累计到书籍 `TotalMinutes`
- 状态机：`Active → Completed`，与 StudySession 一致

### 2. 连续阅读天数
- 按中国时区（UTC+8）计算自然日，统计最近连续有阅读记录的天数
- 实现复用 study 的 `CalcConsecutiveDaysAsync` 思路，按 `StartedAt` 天去重

### 3. 阅读日历
- 指定年份，返回每天累计阅读分钟数（用于日历热力图）

### 4. 年度报告
- 年度总时长、阅读天数、书籍数量、读完书目、最长连续天数、月度分布

### 5. 进度更新
- 结束阅读会话时，可选更新 `CurrentProgress` 和 `LastPosition`
- 书籍读完（progress >= totalPages）自动置为"已读"

## 五、前端设计

### 页面结构（对齐 study 模块）

```
pages/reading/
  reading.vue        # 我的阅读（书籍列表 + 今日阅读卡 + 入口）
  book-edit.vue      # 添加/编辑书籍（书名/作者/封面/状态）
  book-detail.vue    # 书籍详情（开始/结束阅读、进度、位置、摘抄/笔记）
  notes.vue          # 摘抄与笔记管理
  history.vue        # 阅读历史
  stats.vue          # 阅读统计（日历/连续天数）
  yearly-report.vue  # 年度阅读报告
```

### 入口
- "我的"页新增「📚 我的阅读」入口（与「我的学习」并列）
- 首页可选：今日阅读卡（与今日学习并列）

### 交互要点
- 封面：`uni.chooseImage` 本地上传至微信云存储（与头像上传同机制，不通过微信收集）
- 计时：书籍详情页"开始阅读/结束阅读"按钮，与学习计时一致
- 状态：想读/在读/已读 标签切换

## 六、与学习模块（study）的关系

| 维度 | 学习（study） | 阅读（reading） |
|---|---|---|
| 计时对象 | 学习会话 | 书籍阅读会话 |
| 是否有实体 | 无（纯时长） | 有（书籍+进度+摘抄） |
| 统计 | 学习时长/周报/月报 | 阅读时长/日历/年度报告 |
| 连续天数 | 学习连续天数 | 阅读连续天数 |
| 复用点 | — | 时区处理、连续天数、报告结构、DTO 模式 |

两模块并列，不共享会话；用户可同时学习 + 阅读计时（互不干扰）。

---

## 七、整改合规

- 阅读为纯个人工具，无社交、无 UGC 公开
- 摘抄/笔记仅本人可见，不做分享、不开放社区（对齐"先工具后平台"原则）
- 封面本地上传（不收集微信头像/昵称）
- 不涉及联系方式、精确位置
