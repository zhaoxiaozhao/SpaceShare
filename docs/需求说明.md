# 公益共享座位平台——需求说明

## 1. 项目概述

### 1.1 项目名称
暂定：**共享座位 / SeatShare**

### 1.2 产品定位
一个面向图书馆及公共学习空间的免费座位共享与预约平台。

核心理念：

> **免费共享、免费预约、真实到场、不允许座位买卖。**

用户可以分享自己当前正在使用的座位未来一段时间的空闲时间，其他用户可以免费预约。平台通过预约、到达确认、自动释放、信用体系和风控机制，提高公共座位利用率，降低占座和黄牛行为。

### 1.3 商业模式
平台核心功能免费。

收入来源：
1. 微信/平台广告
2. 本地商家推广
3. 品牌广告
4. 用户自愿赞助/支持项目

禁止：
- 座位收费
- 座位转卖
- 通过平台撮合座位交易
- 赞助换取预约特权

用户赞助仅用于项目服务器、运维、审核和开发等成本。

# 4. 核心业务规则

## 4.1 座位原则

平台不拥有实体座位。

平台只记录：
- 场馆
- 楼层
- 区域
- 座位
- 当前使用状态
- 用户主动共享的时间段

用户不得宣称拥有座位所有权。

## 4.2 座位交易原则

禁止任何座位买卖。

禁止：
- 出售座位
- 出租座位
- 竞价座位
- 付费转让
- 通过平台撮合交易

发现后：
- 取消相关预约
- 扣除信用
- 必要时限制账号
- 严重情况封禁

## 4.3 同时有效预约限制

默认：

> 一个用户同一时间只能拥有一个有效预约。

后续可以根据业务数据调整。

## 4.4 预约时间

默认：
- 最短预约：30分钟
- 最长预约：4小时
- 默认最多提前24小时预约

具体值应支持后台配置。

## 4.5 到达确认

预约开始后，用户必须在规定时间内确认到达。

建议：
- 开始前可查看预约
- 开始后进入到达确认阶段
- 超过15分钟未确认：预警
- 超过30分钟未确认：自动释放

时间规则必须后台可配置。

## 4.6 地理位置

可以通过地图/定位进行粗粒度到达校验。

默认允许场馆周边一定范围内确认到达。

不要把精确位置公开给其他用户。

## 4.7 真实使用原则

建议：

> 只有用户完成到达确认后，才可以分享当前座位未来的空闲时间。

防止黄牛虚构座位。

## 4.8 分享座位

分享者必须：
1. 当前已经确认到达
2. 当前拥有有效使用状态
3. 指定未来空闲时间
4. 座位属于当前使用场馆

一个用户同一时间只能维护一个当前使用座位。

## 4.9 候补

如果座位已被预约：
- 用户可以加入候补
- 原预约取消后自动通知候补
- 候补获得短时间优先预约窗口
- 超时自动让位下一候补

## 4.10 联系方式

平台不提供站内聊天。

可以支持：

> 预约成功后，由座位分享者主动授权联系方式。

联系方式默认不公开。

可以使用：
- 微信号
- 微信二维码
- 其他允许的联系方式

严禁通过公开备注发布联系方式进行商业交易。

# 6. 信用体系

初始信用分：

> 100

建议行为：

正常到达：
+1

正常完成预约：
+1

提前取消：
0

预约后未到：
-5

恶意占座：
-10

虚假座位：
-10

座位交易：
-20

恶意举报：
-10

多次违规：
限制功能

信用等级示例：

- 90～100：优秀
- 70～89：正常
- 50～69：观察
- 30～49：限制
- 0～29：高风险

实际分值由后台可配置。

# 7. 反黄牛/风控

## 7.1 基础规则

- 同时只能一个有效预约
- 每日预约次数限制
- 提前预约时间限制
- 未到场自动释放
- 爽约扣分
- 频繁取消限流
- 热门座位动态限流

## 7.2 风险行为

检测：
- 短时间大量预约
- 高频取消
- 高频爽约
- 多账号异常行为
- 集中抢热门场馆
- 大量举报
- 虚假座位
- 座位交易信息
- 异常设备/账号行为

## 7.3 风险等级

0～30：正常

30～60：观察

60～80：限制

80～100：高风险

风控分值和规则后台可配置。
